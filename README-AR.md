# لقاء المجرّات / Galaxy Encounter

تطبيق Python تعليمي لعرض تفاعل مجرّتين بالجاذبية، مع نجوم زرقاء وبرتقالية
وعرض ثلاثي الأبعاد. هذه النسخة ذات المظهر الأصلي الواضح، بعد إزالة لوحة
صور القلب والوردة والفئران والبطريق من الواجهة. تحديثات النموذج المركّب
التجريبية والأذرع الابتدائية الجديدة ليست ضمن هذه النسخة.

## التشغيل

استخدم Python 3.11 أو 3.12. احتفظ بملف `main.py` ومجلد `galaxy_app`
وملف `requirements.txt` معاً. أنشئ بيئة Python افتراضية وفعّلها كما في
[تعليمات التثبيت](README.md)، ثم:

```sh
python -m pip install -r requirements.txt
python -m pip install numba
python main.py
```

Numba اختياري ويسرّع الحسابات على المعالج. SciPy غير مطلوب. لتجهيز أولي أخف:

```sh
python main.py --fast-start
python main.py --fast-start --no-jit
```

على Windows يمكن استعمال `pythonw main.py` للتشغيل دون نافذة أوامر، بعد
تثبيت المكتبات. لا تغيّر إعدادات أمان Windows. الاختصار القديم الموجود
بالمستودع مرتبط بمسار جهاز محدد؛ استخدم أوامر التشغيل على جهازك.

## التحكّم

- `Space`: تشغيل وإيقاف مؤقت. `R`: إعادة البداية. `N`: لقاء عشوائي جديد.
- شروط البداية: انحراف المرور، سرعة الاقتراب، نسبة الكتل وميل القرص،
  مع أرقام وتوضيح للقيم. اضغط Apply بعد تعديلها.
- إعدادات جاهزة، وتجربة مجرّة معزولة، وخيارات لدقة الحساب وعدد النجوم المرئية.
- سحب يساراً للتدوير، ويميناً للتحريك، وعجلة الماوس للتكبير والتصغير.
- Tracking camera لمتابعة المشهد وتأطيره تدريجياً.
- تحكّم بالألوان والسطوع وحجم النقاط، وحفظ PNG وحالات المحاكاة والرجوع بالزمن.
- `C`: وضع العرض السينمائي. `F`: ملء الشاشة. ويوجد شرح عربي للمقدّم.

## حدود النموذج

الجسيمات المادية تمثّل عيّنات نجمية ومادة مظلمة تتفاعل بالجاذبية. كثير من
النجوم المرئية جسيمات اختبار بلا كتلة، تستخدم تقريباً للمجال وخطوة زمنية
تختلف عن الجسيمات المادية. توزيع الأذرع الابتدائي معدّ للعرض؛ ليس دليلاً على
توليد مجرّات حلزونية مستقرة ذاتياً.

التهيئة تقريبية، وتوجد آثار لدقة العينة وتسخين القرص. لا نحسب الغاز أو
الغبار أو ولادة النجوم، ولا نضمن شكلاً معيناً أو اندماجاً أو إعادة بناء
مجرّتين مرصودتين. الزمن والمسافات بوحدات نموذجية، والألوان لتمييز الأصل.
حركة الكاميرا وسرعة المشاهدة لا تغيّران قانون الجاذبية. حفظ الطاقة وحده لا
يثبت دقة النموذج الفيزيائي.

اختبارات الحساب والواجهة مذكورة في README.md. الواجهة المخصصة للزائر هي
المحاكاة الحرة، مع الاحتفاظ ببعض الوحدات القديمة للتوافق والاختبارات.
